# Security Policy

`keychain-store` reads and writes sensitive values through the macOS Keychain. Please report a vulnerability privately rather than opening a public issue.

When this repository is public, use [GitHub private vulnerability reporting](https://github.com/biw/keychain-store/security/advisories/new). Include the affected package version, a minimal reproduction, the macOS and Node versions, and whether the issue needs a signed host, iCloud Keychain, or interactive authentication.

Please do not publish exploit details until a fix is available.
